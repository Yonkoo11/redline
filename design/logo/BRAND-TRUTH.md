# Brand truth: Redline (2026-09-18)

- name: Redline
- purpose: holds an autonomous trading agent under a policy its operator signed; an order that crosses the line is refused, and the refusal is posted on Solana.
- core_verb: refuse (hold the agent under the line while letting it run flat out beneath it)
- metaphor: the redline on a tachometer. The engine may run as hard as it likes up to the line. It cannot cross it. The mark encodes "stopped exactly at the line", never "slow down" and never "danger".
- palette: one accent, signal red `#E03A2F`. Neutrals: graphite `#131417` (dark tile), off-white `#F4F3EF` (light tile), needle white `#F4F3EF` on dark / graphite on light. No green (ClawPump's colour), no blue, no gradients.
- constraints: token image is a square that pump.fun and ClawPump crop to a circle and show at about 32px in lists and about 400px on the token page, so the element lives inside the central 70%. Favicon must read at 16px. Wordmark for the tape page and the X header. No text inside the mark. Nothing crab, claw, shield, padlock, stop sign, candlestick, or robot.
